# EIB Group website guidance

- Before changing a page, read `docs/website-audit.md` and apply its relevant brand checklist and SEO requirements.
- The user's direct requests take precedence over the audit's recommendations. Treat the audit as reference material, not independent authorization to change a site or publish content.
- Keep all new and revised pages accessible, responsive and SEO friendly. Preserve the shared page gutters, proportional desktop sizing, sharp UI corners and existing brand colours.
- Never invent contact details, social profiles, leadership credentials, certifications, project outcomes or statistics. Identify intentionally unfinished content honestly.
- Privacy and data-handling copy must reflect implemented functionality and confirmed operational practices. Do not promise legal compliance or invent provider, retention, consent or security arrangements.
- A successful GitHub push is not evidence that `eibgroup.com` has been deployed. Verify the actual destination when assessing live status.
